accounts that remember everything. Draft, 31 October 2026, on the `plan/gates-and-payments` branch only.

1. [JOURNEY-MAP.md](JOURNEY-MAP.md): what is free, what can be offered and what is behind each gate, and the open decisions.
2. [ACTION-PLAN.md](ACTION-PLAN.md): the build, phase by phase, written so Claude or Chris can implement each task.
3. [BACKABUDDY-COPY.md](BACKABUDDY-COPY.md): the words that link the BackaBuddy campaign to the Mahalaverse.
4. [RESEARCH.md](RESEARCH.md): PayFast, BackaBuddy, Supabase, POPIA, currencies and precedents, with sources.

This repo is public and its main branch is the live website. Keep this folder off main, or move it to the private
Mahala OS repo.
